# exp_036 — 피처 간소화/최적화 탐색

## 실험 개요 (시작 전에 작성)

- **실험 ID**: exp_036
- **날짜 / 담당자**: 2026-08-23 / (Claude, 사용자 요청 — 애초 계획엔
  있었으나 시간 소모 때문에 세션 초반엔 보류, 사용자가 "밤새 마저
  돌리자"고 재개 지시)
- **가설**: 105개(exp_030 기준) 피처 중 58개 파생 피처를 개념 그룹
  10개로 묶어 그룹째로 빼봐도 손해가 노이즈 수준(<2점)이면, 그
  그룹은 불필요한 복잡도다. 공식 원본 47개는 exp_004 선례(제거가
  전부 손해였음)에 따라 탐색 대상에서 제외.
- **기준(baseline)**: exp_030_repro, score=875.00. 그룹 스크리닝은
  raw 105피처 단일시드(818.79 근방) 대비 델타로 먼저 스크리닝, 최종
  후보만 진짜 보정체인까지 거쳐 875.00과 비교.
- **방법**: Phase 1(그룹 10개 개별 제거 스크리닝, 단일시드 빠른 fit)
  → Phase 2(안전 판정 그룹을 안전한 순서로 그리디 누적 제거, 손해가
  나기 직전에 중단) → Final(살아남은 최종 피처셋으로 진짜 5-fold×2
  시드 OOF + exp_030과 동일 보정체인, GO/NO-GO).
- **GO 기준**: exp_036은 "점수를 올리는" 실험이 아니라 "손해 없이
  간소화하는" 실험이므로, 875.00 대비 **-2점 이내**(악화 안 함)면
  GO로 판단(exp_037/031처럼 +2점 개선을 요구하지 않음).
- **누수 위험 검토**: 순수 정적 피처 리스트 편집일 뿐, `fit_shrinkage_
  priors`/`fit_season_state_priors` 등 train-only fit 로직은 전혀
  안 건드림 — 신규 누수 표면 없음.
- **주의(2026-08-22 밤 교훈)**: 같은 밤 먼저 제출한 exp_033_season_
  decay_090_quick이 로컬 2024 홀드아웃에서 +6.21 개선을 보였는데
  실제 LB에서는 exp_030 대비 -9.37 하락했다(`SUBMISSION_LOG.md`
  참고). 피처 제거는 시즌 가중치 조정과 메커니즘이 달라 같은 실패
  양상이 반복될 가능성은 상대적으로 낮다고 보지만, 이 실험의 로컬
  GO 판정도 액면 그대로 신뢰하지 말고 실제 제출 결과로 재확인 필요.
- **신규 파일**: `src/train_exp036_feature_ablation.py`

**해석**: 98피처(105개 중 7개 제거)로 오히려 +5.28 개선 — 세
컬럼(`pitchmix_diversity`, `pitcher_form_trend` 4개, `experience_log`
2개)이 순수 노이즈에 가까웠고 제거가 정규화 효과를 낸 것으로 보임.
공식 원본 47개와 나머지 51개 파생 피처(count-state/pressure/
interaction/shrinkage/trackman/season-state)는 전부 유의미하게
기여 중임을 재확인 — "105개가 과도했다"는 가설은 부분적으로만
맞음(7/105 ≈ 6.7%만 군더더기, 대부분은 실제로 필요).
